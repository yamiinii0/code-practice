# Code Practice

A collection of programs I write while learning different programming languages and practicing problem solving. I keep adding to it as I learn.

## Folder structure

```
code-practice/
├── C/
├── C++/
├── Python/
└── DSA/
```

## What's inside

- **C**: basics, loops, arrays, pointers, strings, functions
- **C++**: OOP concepts, STL, practice programs
- **Python**: basics, small scripts, practice programs
- **DSA**: data structures and algorithm problems

## How to run

**C**
```
gcc filename.c -o filename
./filename
```

**C++**
```
g++ filename.cpp -o filename
./filename
```

**Python**
```
python filename.py
```
